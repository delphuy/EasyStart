# EasyStart

Windows 桌面快捷启动器。把常用的程序、文件夹、网址收进一块面板，随叫随到，用完即走。

## 它能做什么

- 一块面板管所有常用项：程序、文件夹、文件、网址，加进面板就能一键启动
- 多页签分类：按自己的使用场景分页签，悬停、滚轮、数字键都能切换
- 随叫随到：全局热键呼出、鼠标中键呼出，失焦自动隐藏，平时不占桌面
- 网址自动抓图标：添加网址自动抓取网站图标，好看也认得快
- 图标随你换：任意项都可以换成自己的图标文件
- 系统动作一键搞定：关机、锁定、静音、任务管理器、回到桌面，直接钉在面板上
- 备忘录：面板里带一块随手记的地方
- 外观可调：深色 / 浅色主题、图标大小、面板透明度
- 数据备份 / 恢复：托盘菜单一键把全部配置和图标打包带走，换电脑、误删都不慌
- 开机自启可选，托盘常驻，安静不扰

## 特点

- 轻量：体积小、启动快、后台安静
- 仅支持 Windows
- 免安装也能跑：绿色版就一个 exe 文件，下载后直接双击使用，也提供标准安装包

## 使用

1. 下载安装包安装，或下载绿色版 `EasyStart_1.0.2_Portable.exe`，不用安装直接双击使用
2. 首次启动后在托盘图标上右键进入「设置」，把热键和外观调到顺手
3. 面板里的项右键即可编辑、删除、换图标；重要配置记得用托盘菜单「备份数据」留底

> 数据保存在本机 %LOCALAPPDATA%\EasyStart，不上传任何服务器。
